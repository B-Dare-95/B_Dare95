## Changes for the home page "Find a tool" tabs

- **Automations:** remove DWG to RVT.
- **New tab "CAD":** DWG to RVT, CAD to Lines, Import CAD blocked.
- **Modify:** keep Columns, Stairs and Views. Move Walls, Floors, Shafts, Ceiling and Rooms into a new tab, e.g. **"Contextual"** (or one tab per B95 panel), and add Split at Beams under Walls.
- **QoL:** move Pre-Filter Selection to the new contextual tab (B95-Selection).
- **Inspection:** remove BIM Brother. Add Model Watcher under a new **"Monitoring"** tab, or note it lives in the Collaborate tab.
- **Warnings:** rename War Chart to Warning Chart.
